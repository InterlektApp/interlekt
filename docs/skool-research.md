| Stripe integration | ✅ | Skool processes payments via Stripe |

### 3.3 Platform Fees

| Plan | Fee Structure | Notes |
|------|---------------|-------|
| Hobby | 10% + $0.30 per transaction | All transactions |
| Pro | 2.9% + $0.30 per transaction | For transactions up to $899 |
| Pro (high-ticket) | 3.9% + $0.30 per transaction | For transactions above $900 |

**Key detail:** Skool's fees are all-in — there is no separate Stripe fee on top. Skool bundles payment processing into their transaction fee. This is cheaper than using Stripe directly for international cards (Stripe charges an additional 1.5% for international cards and 0.5% for subscriptions).
